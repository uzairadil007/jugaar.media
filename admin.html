How do I get a token?
  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access → Only select repositories → pick this repo
  3. Permissions → Contents → set to Read and write
  4. Set an expiration date, generate, and paste the token above

This token stays only in this browser's local storage and is sent only to GitHub's API — never anywhere else. Treat it like a password: don't share this page's local storage, and set an expiration when you create it.
